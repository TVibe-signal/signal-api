What is TVibe?

TVibe x402 is a Solana token signal API built for AI agents — and for humans who want an agent-grade answer before they touch a new token.

THE PROBLEM

New Solana tokens move fast. Most of them end badly.

71% of the tokens we tracked ended badly within 24 hours: price down 50%, liquidity down 70%, or the pair gone. A human cannot read mint authority, LP lock, holder churn, and exit liquidity for every token in time. An agent can — if it has one clean signal.

THE SOLUTION

One call. One verdict. With reasons.

Paste any Solana mint. TVibe returns a verdict (OK / Caution / Avoid), the blockers, cautions, positives, what is still unknown, and what leaving would cost. No API key to start. No dashboard to learn. One JSON request.

How it works

Three steps. No setup. No key for the free tier.

STEP 01

1. Send a mint

One HTTP request, or one MCP tool call. Example: /signal?mint=So11…1112

STEP 02

2. TVibe reads 4 sources

DexScreener, Solana RPC, RugCheck, and Jupiter. Security, holders, liquidity, and exit quotes — combined into one score.

STEP 03

3. You get a verdict

PASS = proceed, REVIEW = wait 15 min and re-check, SKIP = walk away. Every verdict is recorded and judged ~24h later.

What one call gives you

Four data sources read for you, combined into one decision-ready answer.

Verdict with reasons

OK, Caution, or Avoid — plus blockers, cautions, positives, and what is still unknown.

02 / EXPLAINED

Explained verdicts

Each verdict can be explained flag by flag, in English or Vietnamese: the points each flag adds and what would change the result.

03 / HOLDER
51/100

FAQ — what people ask

What does PASS / REVIEW / SKIP mean?

PASS = proceed, the token passed the checks. REVIEW = wait 15 minutes and check again — the token is not yet proven. SKIP = walk away, the token failed hard checks. In the old wording: PASS = OK, REVIEW = Caution, SKIP = Avoid.

Do I need an API key?

No. Free tier needs no key: 30 requests / minute / IP. If you need more, request a key — it raises the limit to 300 / minute.

How do I use TVibe from Claude / Cursor?

Paste the MCP URL into your MCP client: https://signal-api-24q4.onrender.com/mcp — then ask your agent to check a token. Tools: get_token_signal, check_token_risk, check_tokens_batch, check_exit, get_track_record.

What is Filter v4 Private?

A private, anti-manipulation filter with hidden thresholds, daily jitter, and a two-stage check. It runs in Shadow Mode first, then live. No private thresholds are published on this page.

Is this financial advice?

No. TVibe is a heuristic signal, not a security audit and not financial advice. Always check the reasons, not just the verdict.
